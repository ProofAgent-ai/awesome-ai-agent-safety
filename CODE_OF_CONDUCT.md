# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give credit, and keep discussion about the work. Harassment of any kind is not tolerated.

Report unacceptable behaviour to the maintainers by opening a private [security advisory](https://github.com/ProofAgent-ai/awesome-ai-agent-safety/security/advisories/new) or through the contact page at [proofagent.ai](https://proofagent.ai). Reports are handled confidentially.
