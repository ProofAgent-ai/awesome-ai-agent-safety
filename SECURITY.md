# Security policy

The code in this repo is **educational**. The `local` guard is intentionally simple and is **not** a production control.

- **A bypass of the local guard** is not a vulnerability. Please open a normal PR that adds it as a lab scenario (`known_gap: true`), so everyone learns from it.
- **A real vulnerability in the code** (for example, a lab script that runs untrusted input): report it privately through [GitHub security advisories](https://github.com/ProofAgent-ai/awesome-ai-agent-safety/security/advisories/new).
- **Vulnerabilities in a listed third-party tool** should go to that project, not here.
